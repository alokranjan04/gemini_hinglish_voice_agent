# ✦ Jyotish Mitra — AI Vedic Astrology Voice Assistant

> *"Aapki janam kundali ke zariye, aapke jeevan ki raah dikhana — yahi mera kaam hai."*

A production-grade, real-time Vedic astrology voice agent powered by **Gemini Live API** and **Vobiz Telephony**. Users call a regular phone number, have a natural Hindi/Hinglish conversation, and receive a personalised 1,500-word kundali report with a birth chart and full conversation transcript — delivered to their email.

## 🌟 What It Does

| Feature | Detail |
|---|---|
| **Voice-to-voice AI** | Sub-400ms p50 latency using Gemini 3.1 Flash Live |
| **Natural barge-in** | User can interrupt mid-sentence; AI stops instantly |
| **Confirmation gate** | Reads all birth details back (full year, AM/PM) before proceeding |
| **Birth time rectification** | Collects 2 life events to align the chart |
| **1,500-word Kundali** | Generated by Gemini 1.5 Flash — 7 detailed sections in Hindi |
| **South Indian chart** | 4×4 house grid with 9 planets in individual colours |
| **Full transcript** | Entire conversation included in the email as styled bubbles |
| **Cross-call memory** | Remembers name, kundali, last topic — greets returning callers by name |
| **Auto-save** | Memory saved even if call drops unexpectedly |

## 🗣 Conversation Flow

Every call follows this exact sequence. The AI never skips a step.

```
STEP 0 │ INTRODUCTION
       │ AI introduces itself — what it is, what it does, why it needs details.
       │ Waits for user to agree before asking anything.
       │
STEP 1 │ NAME
       │ "Bahut achha! Sabse pehle apna naam bataiye."
       │
STEP 2 │ DATE OF BIRTH
       │ "Aapki janam tithi kya hai?"
       │
STEP 3 │ TIME OF BIRTH + AM/PM  ← always asked together
       │ "Aur janam ka samay? Subah ka tha ya raat ka — dono bata dijiye."
       │ If only time given → immediately asks "Ye X subah ka tha ya raat ka?"
       │ NEVER assumes AM or PM.
       │
STEP 4 │ PLACE OF BIRTH
       │ "Aur janam ka sheher kaunsa tha?"
       │
STEP 5 │ ⚠ CONFIRMATION GATE — hard block, cannot be skipped
       │ "Ek baar confirm kar leti hoon —
       │  Naam: [X]. Janam Tithi: [DD Month YYYY]. Samay: [HH:MM SUBAH/RAAT]. Sheher: [X].
       │  Kya ye sab bilkul sahi hai?"
       │ Waits for YES. Fixes and repeats if anything is wrong.
       │ Proceeds ONLY after explicit confirmation.
       │
STEP 6 │ LIFE INCIDENT 1
       │ "Janam samay sahi karne ke liye 2 badi events chahiye. Pehli ghatna — kab, kya?"
       │
STEP 7 │ LIFE INCIDENT 2
       │ "Aur ek aur badi ghatna?"
       │
STEP 8 │ EMAIL  ← verified before proceeding
       │ "Aapka email kya hai?"  →  "Maine note kiya: X. Sahi hai?"
       │
STEP 9 │ HOOK
       │ 2–3 sharp personality insights + 1 emotional trigger from the chart.
       │
STEP 10│ CONCERN
       │ "Career, Paise, Love, ya Health — kya hai sabse badi tension?"
       │
STEP 11│ DEEP ANALYSIS
       │ Mahadasha/Antardasha, 1–2 year predictions, key strength/challenge.
       │
STEP 12│ SEND REPORT
       │ "Main abhi aapki Kundali report bhej rahi hoon." → email dispatched.
       │
STEP 13│ SAVE MEMORY
       │ Name, birth details, planets, last topic, summary saved to memory.
```

**Returning callers** (recognised by phone number) skip Steps 0–8 and receive:
> *"Namashkar [Name] ji! Aapki kundali mere paas hai. Mujhe yaad hai ki aapne [last_topic] ke baare mein poocha tha. Aaj main aapko kis tarah madad kar sakti hoon?"*

## 📧 The Email Report

Every report contains four sections:

### 1. Birth Details Table
Name, Date of Birth, Time of Birth (with SUBAH/RAAT), Place of Birth.

### 2. South Indian Kundali Chart
A 4×4 house grid with all 9 planets placed in their calculated houses, each in its unique colour.

### 3. Detailed Kundali Analysis — 1,500+ words in Hindi (Devanagari)

| Section | Content | Min Length |
|---|---|---|
| व्यक्तित्व एवं स्वभाव | Lagna, Rashi, Nakshatra, personality | 200 words |
| करियर एवं आर्थिक स्थिति | 10th/2nd/11th house, Raj Yogas | 250 words |
| पारिवारिक जीवन एवं विवाह | 7th/4th house, Venus, Jupiter | 200 words |
| स्वास्थ्य | 6th/8th house, Moon indicators | 150 words |
| विशेष राजयोग एवं दोष | All Yogas and Doshas | 200 words |
| दशा एवं भविष्यफल | Mahadasha, 1/3/5 year predictions | 200 words |
| ज्योतिषीय उपाय | 6–7 remedies, mantras, gemstones | 150 words |

The report is generated by a **dedicated Gemini 1.5 Flash API call** after the call — not from the voice session — ensuring full depth and detail.

### 4. Conversation Transcript
The complete call transcript, formatted as styled chat bubbles:
- **Gold bubble** = User messages
- **Amber bubble** = Jyotish Mitra responses

## 🧠 Returning Caller Memory

Caller profiles are stored in `user_memory.json` and persist across calls.

**What is stored:**
```json
{
  "9801234567": {
    "name": "Alok",
    "dob": "15 March 1981",
    "tob": "01:20 AM",
    "pob": "Delhi",
    "email": "alok@gmail.com",
    "planets": "Sun=1,Moon=4,Mars=8,Mercury=1,Jupiter=5,Venus=12,Saturn=7,Rahu=3,Ketu=9",
    "last_topic": "Career",
    "conversation_summary": "Predicted career change in 2026-27 during Jupiter Mahadasha.",
    "last_call_date": "27 April 2026",
    "call_count": 3
  }
}
```

Memory is **merged** on every call — existing data is never overwritten by a partial update. Even if the AI never explicitly calls `save_user_profile`, the `finally` block auto-saves whatever state was captured.

> ⚠️ **Production note:** `user_memory.json` is instance-local. For multi-instance deployments, replace with Firestore or Redis.

## 🛠 Setup & Local Testing

### Prerequisites
- Python 3.11+
- A Vobiz account with a virtual number
- A Google AI Studio API key (Gemini)
- A Gmail account with an App Password enabled

### Install & Run

```bash
# Clone the repo
git clone https://github.com/alokranjan04/Jyotish_Voice_Agent.git
cd Jyotish_Voice_Agent

# Create virtual environment
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Create .env file
cp .env.example .env
# Fill in your keys (see Environment Variables below)

# Run the server
python main.py
# Server starts on http://0.0.0.0:8080
```

### Test with ngrok (local Vobiz routing)

```bash
# Install ngrok, then:
ngrok http 8080

# Set your Vobiz webhook to: https://<ngrok-url>/answer
# Call your Vobiz number
```

## 🚀 Deployment

Deployment is fully automated via **GitHub Actions** on every push to `main`.

### Pipeline

```
git push origin main
        ↓
GitHub Actions (deploy.yml)
  1. Authenticate to Google Cloud (GCP_SA_KEY secret)
  2. Configure Docker → Artifact Registry
  3. docker build + docker push
  4. gcloud run deploy jyotish-voice-agent
        --region us-central1
        --timeout 3600
        --set-env-vars GEMINI_API_KEY, GMAIL_USER, GMAIL_APP_PASSWORD
```

### Required GitHub Secrets

| Secret | Value |
|---|---|
| `GCP_SA_KEY` | Google Cloud service account JSON (base64 or raw) |
| `GEMINI_API_KEY` | Your Gemini API key |
| `GMAIL_USER` | Gmail address |
| `GMAIL_APP_PASSWORD` | Gmail App Password |

### Cloud Run Config

| Setting | Value |
|---|---|
| Region | `us-central1` |
| Timeout | `3600s` (supports 60-min consultations) |
| Memory | 512MB (default) |
| Auth | Unauthenticated (required for Vobiz webhook) |
| Project | `testcnx-169610` |
| Image | `us-central1-docker.pkg.dev/testcnx-169610/jyotish-repo/jyotish-voice-agent` |
